# 2022 개정 교육과정 초등 수업 설계 도우미

초등학교 1~2 / 3~4 / 5~6학년군의 **성취기준 611개**, **성취기준 해설 328개**,
**영역별 성취수준 126개**, 그리고 교과 교육과정의 **내용 체계**(영역 · 핵심 아이디어 153문장 ·
범주별 내용 요소 928항목)를 한자리에서 찾아보고 내려받는 도구입니다.

**바로 쓰기 →** https://lo4lolo.github.io/achievement-criteria/

## 무엇을 할 수 있나요

- **찾기** — 낱말 일부만 넣어도 찾습니다. 띄어쓰기를 무시하고, 코드(`2국01`)와 초성(`ㅅㅌㅎㄱ`)으로도 찾습니다.
  성취기준 본문뿐 아니라 성취수준과 해설 속 낱말까지 함께 찾습니다.
- **성취기준 · 성취수준** — 성취기준, 성취기준 해설, A·B·C 성취수준, 교육과정에 제시된 탐구 활동을 한 화면에서 봅니다.
- **내용 체계** — 그 성취기준이 속한 영역의 **핵심 아이디어**와 학년군별 **내용 요소**(지식·이해 / 과정·기능 / 가치·태도)를 봅니다.
- **수업·평가 계획** — 성취기준별 **교수·학습 내용**(단원명 칸에 쓸 요약과 차시 흐름)과
  **평가 영역·요소·방법·횟수** 초안을 받습니다. 평가 기준은 성취수준 A·B·C 원문을 그대로 씁니다.
  교육과정 자료에 **예시 평가 도구**가 있는 성취기준은 평가 요소·도구 유형·배점을 원문 그대로 보여 줍니다.
- **개념 기반 탐구** — 개념적 렌즈 · 핵심 개념 · 일반화 문장 · 탐구 질문 초안과
  성취기준 적용 시 고려 사항, 교과 역량을 함께 봅니다.
- **연관 · 위계** — 같은 영역의 학년군별 성취기준(위계)과, 같은 학년군 다른 교과의 연관 성취기준을 찾습니다.
- **개념 지도** — 성취기준–개념–성취기준 관계를 그림으로 봅니다. 개념을 눌러 펼치고, 끌어서 옮기고, 확대·축소할 수 있습니다.
- **내려받기** — 수업 바구니에 담아 **MD**(인공지능과 이어서 설계) · **평가계획 CSV**(시기·성취기준·단원명·평가
  영역·요소·방법·횟수·성취수준 칸) · **CSV** · **표 복사**(한글) · **인쇄/PDF**로 내보냅니다.

## 영역에 대하여

이 도구의 **영역**은 교육과정 **내용 체계**에서 핵심 아이디어 위에 놓인 제목을 가리킵니다.

- 국어 · 수학 · 도덕 · 체육 · 음악 · 미술 · 영어 · 실과 — 성취기준의 영역과 내용 체계의 영역이 같습니다.
- **사회 · 과학** — 성취기준이 **단원** 단위로 제시되어 내용 체계의 영역과 다릅니다.
  교육과정에 단원↔영역 대응표가 없어 내용 요소·핵심 아이디어·단원명을 견주어 단원 단위로 이어 붙였고,
  화면에서 **직접 바꿀 수 있습니다.** 바꾸면 핵심 아이디어와 내용 요소가 함께 따라옵니다.
- 영역 칩의 `1~2·3~4·5~6` 표시는 그 영역이 학년군에 걸쳐 이어진다는 뜻입니다.

## 파일

| 파일 | 설명 |

인터넷 없이 쓰는 **단일 파일본**은 저장소 바깥의
`2022개정 초등 수업설계 도우미 (오프라인용).html` 하나로 배포합니다. 더블클릭하면 바로 열립니다.

## GitHub Pages로 게시하기

1. 저장소의 **Settings → Pages** 로 갑니다.
2. **Source** 를 `Deploy from a branch` 로 둡니다.
3. **Branch** 에서 `achievement-criteria` 와 `/ (root)` 를 고르고 **Save** 합니다.
4. 1~2분 뒤 위 주소에서 열립니다.
