# 2022 개정 교육과정 초등 성취기준·성취수준 찾기

초등학교 1~2 / 3~4 / 5~6학년군의 **성취기준 611개**와 **영역별 성취수준 126개**를
한 화면에서 찾아보고 내려받는 도구입니다. 파일 하나로 동작하며 인터넷 없이도 열립니다.

**바로 쓰기 →** https://lo4lolo.github.io/achievement-criteria/

## 무엇을 할 수 있나요

- **부분 일치 검색** — 낱말 일부만 넣어도 찾습니다. 띄어쓰기를 무시하고, 코드(`2국01`)와 초성(`ㅅㅌㅎㄱ`)으로도 찾습니다.
- **영역별 보기** — 교과를 고르면 영역이 나오고, 학년군에 걸쳐 이어지는 영역은 따로 표시됩니다.
- **학년군 위계** — 수학·국어처럼 위계가 뚜렷한 교과에서 같은 영역의 학년군별 성취기준을 한눈에 봅니다.
- **연관 성취기준** — 같은 학년군의 다른 교과에서 내용이 가까운 성취기준을 찾아 줍니다. 교과 통합·프로젝트 수업 설계용입니다.
- **개념 지도** — 성취기준–개념–성취기준 관계를 그림으로 봅니다. 개념 기반 탐구 수업의 중심 개념을 잡을 때 씁니다.
- **모아서 내려받기** — 수업 바구니에 담아 CSV·표 복사·인쇄(PDF)로 내보냅니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 검색 도구 본체. 자료가 파일 안에 들어 있어 단독 실행됩니다. |
| `achievement-standards.csv` | 성취기준 611개 전체 (UTF-8 BOM, 엑셀·한셀에서 바로 열림) |

## GitHub Pages로 게시하기

1. 저장소의 **Settings → Pages** 로 갑니다.
2. **Source** 를 `Deploy from a branch` 로 둡니다.
3. **Branch** 에서 `achievement-criteria` 와 `/ (root)` 를 고르고 **Save** 합니다.
4. 1~2분 뒤 https://lo4lolo.github.io/achievement-criteria/ 에서 열립니다.

## 구글 사이트에 넣기

구글 사이트의 `삽입 → 코드 삽입`은 **1만 자 제한**이 있어 이 파일을 통째로 붙여 넣을 수 없습니다.
위 GitHub Pages 주소를 받은 뒤,

- 구글 사이트 편집 화면에서 **삽입 → 삽입 → 웹 주소(URL)** 를 고르고
- 그 주소를 넣으면 사이트 안에서 바로 검색할 수 있습니다.
